# PYLens

To view the full documentation, visit [PyLens documentation](https://blairarmstrong.github.io/PyLensPublic/).

Directory structure is as follows

- PyLens/backend: this holds the backend code for building neural networks (i.e. this is where we can train/test our networks)

- PyLens/gui: holds the code for displaying networks to a GUI in an interactive manner

- PyLens/examples: hold the code to structure examples and input data to networks

- examples: examples of different types of neural networks and the example files used

- unit_tests: codes for unit tests

- utils: utility code to do benchmarks

- docs: documentation
