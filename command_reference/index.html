Command Reference¶

Network Commands

  • create_net: Create a new network instance based on the specified type

  • add_net: Adds a new network instance to the simulator

  • use_net: Set the specified network as the active network

  • delete_net: Remove a network instance from the simulator

  • store_network: Save the current network state to a file in either pickle or JSON format

  • load_network: Load a previously saved network from a pickle or JSON file

  • set_time: Set the network’s time parameters

Group Commands

  • add_group: Add a group to an existing network

  • delete_group: Delete a group from an existing network

  • order_groups: Set the order in which groups are updated

  • get_group_type: Print information about a group’s type, input type, and output type

  • change_group_type: Add new input and/or output transforms to a group

  • copy_unit_values: Copy unit values from one group to another group or within the same group

  • print_unit_values: Print basic unit values for a list of groups into a file

  • reset_unit_values: Reset values of a specified field for all units in the group

  • polarity: Compute the average polarization of unit outputs in a group

Connection Commands

  • connect_groups: Create links with a specified pattern between groups

  • connect_group_to_unit: Connect all units in one group to specific units in another group

  • connect_units: Create links between specific units

  • elman_connect: Initialize weights for an Elman connection between two groups

  • copy_connect: Copy values from a specific field of another group

Disconnection Commands

  • thaw_group_inputs: Unfreezes (thaws) specific or all incoming links to a group

  • disconnect_groups: Delete links of a specified type between two groups

  • disconnect_group_units: Delete links from a group to one or more units

  • disconnect_units: Delete links from a group to one or more units

  • delete_links: Delete all links of a specified type

  • delete_group_inputs: Delete incoming links to a group

  • delete_group_outputs: Delete incoming links to a group

  • delete_unit_inputs: Delete incoming links to a unit

  • delete_unit_outputs: Delete outgoing links from a unit

Link Commands

  • freeze: Freezes the weight updates for the link

  • unfreeze: Unfreezes the weight updates for the link

Lesioning and Healing Commands

  • lesion_all_groups: Applies a lesion to all groups in the network

  • lesion_specific_group: Applies a lesion to all groups in the network

  • lesion_all_links: Removes or modifies incoming links to all groups in the network

  • link_specific_lesion: Applies a lesion to specific links between two groups in the network

  • lesion_bias_links: Applies a lesion to the bias links in the network

  • heal_all_groups: Restores lesioned units in all groups within the network

  • heal_specific_group: Restores lesioned units in a specific group

  • heal_all_links: Restores lesioned links across all groups in the network

Noise Commands

  • add_all_links_noise: Applies noise to all links in the network based on a specified distribution

  • add_links_specific_noise: Applies noise to specific links between two groups in the network

  • remove_all_links_noise: Removes noise from all links in the network

  • remove_links_specific_noise: Removes noise from specific links between two groups in the network

Example Commands

  • load_example_set: Reads an example file and loads it into an example set

Training Commands

  • train: Train the network using a specified algorithm

  • set_update_method: Train the network using a specified algorithm

  • update_weights: Update the weights of the links between groups

  • test: Evaluate the network on the testing set

  • reset_network: Reset the network to its initial state

  • reset_derivs: Reset the derivative values for all groups in the network

  • save_stats: Save the training statistics to a file

Parallel Training Commands

  • set_properties: Set the properties of the network as required for parallel training mode
