Overview of the Code¶

This page describes the structure of the most important class objects used in PyLens. PyLens includes three major sets of objects. The first set is the network objects, which include the neural network object and other objects responsible for neural network representation, computation, and training. The second set is the example objects, which represent training and testing example sets in a structure suitable for cognitive modeling. The third set is the GUI objects, which visualize the neural network units, layers, weights, and graphs, and provide command buttons.

Network Classes¶

The backend contains network, groups (layers), links (weights), and optimizer classes.

Network¶

This is the backbone neural network object. It connects other components, such as groups (layers), input/output transformations, and links (weights).

class PyLens.backend.network.Network(
name,

learning_rate=None,
batch_error_threshold=0.0,
group_criterion_threshold=0.0,
num_updates=100,
min_criterion_batches=1,
update_method='STEEPEST',
stats_plotted=None,
pseudo_example_freq=None,
graph_title='error vs Report Interval',
graph_quantity='error',
tk_root=None,
net_res_save_path=None,
output_cost_strength=0.01,
output_cost_peak=0.5,
debug=False,
)¶

The Network class is used to build the architecture of standard neural networks and run examples through the network. It also serves as the base class for other networks.

Groups¶

This is the object representing a group (layer) of units.

class PyLens.backend.group.Group(
name,
num_units,
group_type,
input_transforms,
output_transforms,
time_intervals,
ticks_per_interval,
network,
dropout_rate=None,
num_cols=None,
)¶

This class represents a group (also called layer) of units. It is responsible for processing inputs, applying input transformations, and computing output activations.

Input transformations¶

This is the object that applies an input transformation to a group of units.

class PyLens.backend.inputs.input_transform.Input_Transform(name, group)¶

This class implements the input transformation to a group of units. It serves as the base for different kinds of input transformations.

Output transformations¶

This is the object that applies an output transformation from a group of units, also called an activation function.

class PyLens.backend.output_transforms.basic.Basic(name, group)¶

This class implements the output transformation (activation) from a group of units. It serves as the base for different kinds of output transformations.

Links¶

This is the object representing the links (weights) between two groups (layers) of units.

class PyLens.backend.link.link.Link(
outgoing_group,
incoming_group,
weights,
initialization='uniform',
link_type=None,
dropout_rate=None,
perma_lesion_rate=None,
)¶

Links (weights) between different groups (layers) of neural network. Abstract class that represents different types links: LinkFull, LinkOneToOne, LinkRandom.

class PyLens.backend.link.link_random.LinkRandom(

Initialized to drop drop_prob% of link permanently, if the drop probability is larger than 66%, then use the sparse matrix as random mask, otherwise use numpy dense matrix as mask.

Optimizers¶

This is the object representing the weights between two groups (layers) of units.

class PyLens.backend.optimizer.optimizer.Optimizer(network, lr)¶

Optimizer used to perform gradient descent for the training of neural network. It serves as the base for different optimizing algorithm.

Example Classes¶

There are three example class objects: example set, example, and event. The example iterator iterates over the examples in an example set.

Example Set¶

class PyLens.examples.example_set.ExampleSet(
network,
proc_exists: bool,
name: str,
file_name: str,
input_groups,
target_groups,
default_input: int,
active_input: int,
default_target: int,
active_target: int,
loading_order='ORDERED',
def_s_pipe_loop=True,
def_s_max_time=1.0,
def_s_min_time=0.0,
def_s_grace_time=0.0,
mode='ORDERED',
num_loaded=None,
)¶

It stores a set of examples with similar properties on which the neural network will be trained or tested. Each .ex file contains information used to construct one ExampleSet.

Example¶

class PyLens.examples.example.Example(example_set, frequency=1.0)¶

It stores information related to one example of the ExampleSet and has a list of events which will be executed by the neural network.

Event¶

class PyLens.examples.event.Event(ex)¶

It consist of information related to one event of the Example object and has UnitGroup object as inputs and targets

Example Iterator¶

class PyLens.examples.example_iterator.ExampleIterator(example_set)¶

This class iterates over the examples in an ExampleSet object and keeps track of the current, previous and next example at each iteration. It does not changes original order of the examples in the example array, instead keeps the track of their indices in the array and is also responsible for ordering the example indices based on the value of mode parameter passed in the ExampleSet constructor. Also resets itself once it reaches the end of the array.
